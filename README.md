# 🎮 Neon Play

**Sua central de jogos e desafios!**

O Neon Play é um projeto desenvolvido com HTML, CSS e JavaScript que reúne jogos e atividades interativas em um único lugar. O objetivo é proporcionar diversão, estimular o raciocínio lógico e desenvolver habilidades de forma simples e interativa.

## 🚀 Funcionalidades

### 🎮 Portal de Jogos Neon
Um portal com cinco jogos diferentes para testar habilidades e desafiar o jogador:
- Nave Espacial
- Cobrinha
- Pac-Man Neon
- Corrida Neon
- Desafio do Bloco

### 🧠 Quiz Interativo
Um jogo de perguntas e respostas com categorias como:
- Tecnologia
- Conhecimentos Gerais
- Games
- Filmes
- Ciências

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura das páginas.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Escolha uma das opções disponíveis no menu principal e divirta-se!

O projeto utiliza tecnologias web básicas e não precisa de um processo de compilação para ser executado localmente.

## 🌐 Publicação

O projeto foi preparado para ser publicado no GitHub e hospedado no Vercel, permitindo o acesso pela internet.

## 🎯 Objetivo do projeto

Este projeto tem como objetivo colocar em prática os conhecimentos de desenvolvimento Front-End, trabalhando com estrutura HTML, estilização CSS, lógica JavaScript e organização de arquivos.
